4x4 tank drive

Connect controller inputs to four motors and explain the resulting movement.

Driving basics

Open TeamCode/src/main/java/org/firstinspires/ftc/teamcode/teaching/session1/TankExerciseTeleOp.java in Android Studio. Run Teaching S1 Exercise - 4x4 Tank before looking at the solution.

Read the structure

  1. In init(), find the four hardwareMap.get(...) lines. These names must match the robot configuration.
  2. Find the four direction assignments. The left motors are reversed; the right motors are forward.
  3. In loop(), find the forward and rotate inputs, then the left and right power calculations.
  4. Find where one calculated power is sent to both motors on the same side.

Controls

ControlActionWhat to predict
Left stick YForward and backwardAll four wheels contribute to straight motion
Right stick XRotateLeft and right sides receive different power

Test in a deliberate order

  1. Start with both sticks released. Confirm the robot is still.
  2. Move the left stick forward a small amount. Does the robot move straight?
  3. Move the right stick X without forward input. Does the robot rotate around its center?
  4. Combine forward and turn. Does the robot follow a curve?
  5. Read the telemetry and connect the displayed left/right values to the motion you observed.

The same test can be performed in the simulator and, when hardware is available, with the wheels lifted first and a clear low-speed practice area.

Takeaway

By the end of this lesson, every student should be able to identify the four motor names, explain why motor directions are configured, describe arcade drive as forward plus or minus rotation, and use telemetry to compare a prediction with robot behavior.

Compare with Teaching S1 Solution - 4x4 Tank only after making observations. Optional diagnostic: describe what would happen if one rear motor were omitted; do not edit shared files.

Ask a follow-up question. Stop immediately if the robot behaves unexpectedly.
