Driving basics

Run Teaching S1 Exercise - 4x4 Tank. The left stick drives forward and backward; the right stick turns. Each side powers both front and rear motors.

The code uses the same four names as the configuration and forwardInput() so simulator orientation matches the team baseline.

Controls

ControlAction
Left stick YForward and backward
Right stick XRotate around the center

Safe path

Simulator: select the StarterBot, INIT, START, and drive slowly. Hardware: lift wheels first, verify STOP, then drive in a clear area. Rotate driver, navigator, and observer/debugger.

Compare with Teaching S1 Solution - 4x4 Tank only after making observations. Optional diagnostic: describe what would happen if one rear motor were omitted; do not edit shared files.

Ask a follow-up question. Stop immediately if the robot behaves unexpectedly.

Primary source: FTC gamepad documentation.
