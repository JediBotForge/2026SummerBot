Button state and speed

Run Teaching S2 Solution - Speed Toggle. Tap the right bumper once: speed changes between FULL and SLOW.

Holding the bumper does not repeatedly toggle because the program remembers the previous button state.

Try it

  1. Run the exercise first.
  2. Tap, hold, and release the bumper.
  3. Explain why one tap changes the mode only once.
  4. Use the solution to compare the remembered button state.
Ask a follow-up question. Stop immediately if the robot behaves unexpectedly.
