From INIT to LOOP

Learn where an opmode lives, how to read it, and how to run it safely.

Workflow

This lesson is about the path from a Java file to a running robot program. You are not expected to write Java yet.

Open the opmode in Android Studio

  1. Open the repository in Android Studio.
  2. In the left Project panel, choose the Project view if needed.
  3. Expand TeamCode, then src, main, java, org.firstinspires.ftc.teamcode, teaching, and session1.
  4. Open WorkflowExerciseTeleOp.java. Keep WorkflowSolutionTeleOp.java available for comparison later.
  5. Find the class name and the @TeleOp line near the top. The name in that annotation is what appears in the simulator's opmode list.

Find the two important methods

Scroll through the class and locate these methods:

init()

Runs once after you press INIT. It prepares hardware and displays the initial telemetry.

loop()

Runs repeatedly after you press START. It reads the gamepad, changes outputs, and refreshes telemetry.

Use the editor's search shortcut, usually Ctrl+F, to find init and loop. Do not worry about understanding every line yet; identify when each method runs.

Run it from Android Studio

  1. In the Android Studio toolbar, open the run-configuration dropdown.
  2. Select the Simulator run configuration.
  3. Click the green Run button. Android Studio builds and opens the desktop simulator.
  4. Choose Stryker: StarterBot.
  5. Select Teaching S1 Solution - Workflow.
  6. Press INIT, then predict the telemetry before pressing START.
  7. Press START, press A, and move the controller stick.
  8. Press STOP before changing the selected opmode or code.
Ask a follow-up question whenever a word or step is unfamiliar. The goal is understanding the cycle, not memorizing Java syntax.

Takeaway

By the end of this lesson, every student should be able to point to an opmode in Android Studio, identify its init() and loop() methods, select its registered name in the simulator, and explain what changes after INIT, START, and STOP.
