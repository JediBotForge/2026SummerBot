Quick reference

Launch and drive.

From the repository root, run:

.\gradlew.bat :Simulator:run
  1. Choose Stryker: StarterBot.
  2. Select a teaching opmode.
  3. Press INIT, then START.
  4. Use a physical gamepad or the simulator controls.

The Java code calls HardwareMapUtil.forwardInput() so pushing forward means forward in both simulator and hardware paths.

Controller options

This repository currently sets USE_VIRTUAL_GAMEPAD = false, so the simulator expects physical USB or Bluetooth gamepads. It does not require REV-branded controllers: ordinary PC-compatible gamepads supported by the simulator's Jamepad/SDL input layer should work.

The simulator supports up to two physical gamepads per running instance. With two controllers, press Start+A on a controller to assign it as gamepad1, or Start+B to assign it as gamepad2.

If a third laptop has no controller, change the local simulator configuration to USE_VIRTUAL_GAMEPAD = true and relaunch the simulator to use its on-screen controls. This is a simulator-only setting and does not affect the robot.
