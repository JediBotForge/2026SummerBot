Prepare the drive profile.

With the REV controller connected and authorized through ADB, run:

powershell.exe -ExecutionPolicy Bypass -File .\robot-configs\scripts\push-configs.ps1

If several Android devices are connected, add -DeviceSerial <serial>. Then refresh Driver Station -> Configure Robot and activate starterbot-drive-only.

The script copies XML configuration files; it does not deploy the Robot Controller APK or activate a profile. Students should observe this workflow rather than edit infrastructure during the first sessions.
